03 — vision work

Six projects from the first year, each one running live on this page.

Nothing below is a screenshot. Every figure is the algorithm it describes, reimplemented small enough to run in your browser, operating on this page instead of on a dataset.

Monocular-to-stereo visual odometry

Python · OpenCV · NumPy
github.com/Ahmad-raml/mono-to-stereo-vo

A classical odometry pipeline on the TUM VI fisheye sequences. The monocular path uses FAST features with Lucas–Kanade tracking and essential-matrix pose; the stereo path adds StereoSGBM disparity and PnP-RANSAC, which is what finally makes the scale metric. Forward–backward flow checks and motion-only bundle adjustment cut PnP failures by over 90%.

  • 33.5 → 22.3 moutdoor ATE
  • 210–503×rel. translation error, stereo vs mono
  • >90%fewer PnP failures

Stereo calibration & 3D reconstruction

Python · OpenCV contrib · Jupyter
github.com/Ahmad-raml/camera-callibration

End to end: chessboard capture, intrinsic and stereo calibration, rectification, epipolar verification, WLS-filtered SGBM disparity, depth maps, and coloured point clouds and meshes. I added an essential-matrix sensitivity analysis to quantify how fast epipolar error grows when the parameters are perturbed.

  • 0.21 pxstereo RMS reprojection error
  • 4 stagescapture → rectify → disparity → cloud

Virtual air canvas

Python · OpenCV · MediaPipe
github.com/Ahmad-raml/virtual-air-canvas

Touchless drawing driven by real-time hand-landmark tracking. An extended index finger paints; an open palm erases. The original reads a webcam — here the landmark model is replaced by your pointer, and everything downstream of it is the same.

Text extraction from images

Python · OpenCV · Tesseract
github.com/Ahmad-raml/Extracting-Text-from-Images

Otsu thresholding, morphological dilation and contour detection segment the page into blocks; Tesseract runs per block; the results are re-ordered by coordinate into natural reading order. The reordering step is the one that actually makes the output usable.

YOLO object detection

Python · OpenCV DNN
github.com/Ahmad-raml/YOLO-object-detection-with-OpenCV

YOLOv3 on COCO through OpenCV's DNN module, across still images, recorded video and a live webcam. The write-up documents where it falls down: small, densely grouped objects, where Faster R-CNN and SSD behave differently.

The version below is pointed at this page. Run it and it will draw boxes over whatever is on your screen right now — and, faithfully, miss the small stuff.

Tower defense — a pathfinding sandbox

C++17 · SFML 3 · CMake
github.com/Ahmad-raml/tower-defense

A real-time game built on a Dijkstra variant over a 4-connected grid with multi-goal search. Agents minimise tower coverage first and distance second, and re-plan the moment a tower is placed or sold — so the interesting behaviour is emergent: they walk the long way round rather than through fire.

04 — manipulation

There is an arm on this page, and it will hand you my CV.

Probabilistic and autonomous robotics, sensor-based control and embedded systems are a third of the master's. So rather than describe them, here is a three-link planar manipulator solving inverse kinematics in real time.

Point anywhere in the frame and the arm reaches for it — the joint angles are solved with FABRIK, iterating until the end effector is within tolerance. Give it a tile and it will pick the tile up, carry it to the inspection slot, and set it down. Ask it for the CV and it will bring you the CV.
